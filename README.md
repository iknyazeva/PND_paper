# Статья ПНД

`main.tex` собирает русскую рукопись, `english_translation.tex` — английские материалы. Разделы находятся в `sections/`, рисунки — в `Figure/`.

Сборка из этой папки:

```bash
/opt/homebrew/Caskroom/miniforge/base/envs/tmfc/bin/python _tools/build_pdf.py
```

Скрипт создает временный формат TeX с русскими переносами, проверяет ссылки и ограничение в 25 страниц, затем обновляет оба PDF. Установленная TeX-система не меняется. Временные файлы остаются в выведенной папке `/private/tmp/`; итоговые PDF и служебные файлы LaTeX исключены из Git.

Рисунок 7 и сводка FV для трех режимов воспроизводятся командой `python _tools/update_correction_figure.py` по сохраненным таблицам `../../experiments/correction_fv_frozen_test/`. Новых симуляций и бутстрепа она не выполняет. Результаты и хеши исходных таблиц сохраняются в `_analysis/`; исходные одновременные верхние границы не пересчитываются.
